How it behaves

  • Stop sits on the running row only. The other action is greyed out with "Waiting for Claude to finish."
  • Stop asks once, inside the menu, then withdraws the request. The book unlocks at once. For a revise, the notes go back to drafts. For a build, the build is marked stopped: its sections go back to Drafting and the evidence already written is kept (the build skill's stop works this way today).
  • If Claude has already started, its session notices the stop the next time it checks (before each section it edits, or each build task), stops there, and says so in the terminal. Whatever it already changed stays in the book, to review like any other change.
  • A guest on a shared link has no Claude menu, so no Stop.
  • Keys: none new. Esc closes the question as it closes the menu.
